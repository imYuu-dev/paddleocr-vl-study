# 叙事调整说明

日期：2026-11-11

## 目标

让没有读过论文的学生从第一屏开始，按教师带读的顺序进入课程：先看人怎样读一份文档、程序在批量整理和跨论文对照时缺什么，再看同一页教学文档和需要保存的记录，随后才命名“文档解析”，让 OCR、Pipeline、VLM、Coarse-to-Fine 等术语沿着需要出现。重点不是增加设问或卡片，而是补齐正文的因果、图前说明和图后解释。

## 文件改动

- `maintenance/build_content.py`：文案唯一生成源。重写 m1；为 m2–m9 增加承接上一模块的导语和正文内的读图/读表引导；新增 8 条模块间 `bridges`，避免“下一步”重复下一模块导语。
- `index.html`：替换 hero 段落，从页面阅读与内容/结构保存讲起，不再用“先看机器需要交回什么”式入口。
- `assets/course/course.js`：把每模块的 `goal` 从 header 移到正文之后，改为“学完后回看”提示；其余渲染、测验、进度和脱稿演练逻辑未改。
- `assets/course/course.css`：新增 `.goal-after` 的回看样式。
- `assets/course/modules.js`：由生成脚本重建。
- `README.md`：补充叙事顺序、保留项与验收结果。

## 各模块叙事

- m1（4 节）：先从人读文档时利用标题、分栏、表格行列和公式上下标的动作讲起，再说明程序在批量整理和跨论文对照时需要保存哪些记录；随后才交代页面图像输入，把 PDF 文字层的限定放在这段末尾；同一页教学文档先说明示例身份，再看图解释元素与关系；之后定义文档解析、内容与结构、Markdown/JSON，并把 Figure S5 放到定义之后；再并列介绍传统 Pipeline、通用 VLM、专用文档 VLM 三条路线，说明可混合、不是历史阶段；最后从整页高分辨率成本收窄到 Coarse-to-Fine。
- m2：承接“先找区域是否值得”的问题，先看 Figure 2 的面积统计，再解释图像块与视觉 Token，最后说明粗阶段找范围、细阶段保留细节及漏检/错裁前提。
- m3：承接“先找区域只是第一步”，先追踪 Figure 3 的整体箭头，再给 VRFM、识别模型和 0.9B 命名；检测这一段留到 m4 展开，不在 m3 提前引入 RT-DETR；文档控件从 stage 0 开始，配合“上一步／下一步”连续讲授。
- m4–m9：每节先交代“这一节看什么、上一节留下什么”；图前只交代困难、为什么看图和必要概念，图后解释现象、结论与下一步，合并图前/图后的重复操作说明；m7 明确训练与推理的区分，m8 先定义指标再读三组实验，m9 先固定复现范围再列证据和定位错误。
- m6 保持 6 节：公式交互、Figure 3 局部、视觉编码器、Projector、语言模型、回填页面；技术讲解没有删减。
